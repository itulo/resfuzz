How it works

Host (Linux)

· mkqnximage image + QEMU (TCG)
· deploy agent over ssh
· triage, bucket, minimise
· core → backtrace via ntox86_64-gdb
· Markdown + HTML report
⇄

QNX 8.0 target

resfuzz-agent (built with qcc)
· mutates open / read / write / lseek / devctl
· raw MsgSend, hand-built io_devctl_t with lying nbytes
· dcmds resolved on target from <devctl.h>
→

Resource manager under test

spawned privately, or attach-only for system services (pipe, random)

Oracles:
· crash: errno + waitpid
· hang: TimerTimeout + watchdog core
· deadline: ClockCycles vs budget
